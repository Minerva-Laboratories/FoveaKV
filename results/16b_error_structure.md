# E16b Structure of the coarse-logit error

**TL;DR:** the 2-bit logit error is mostly Berkson-type: corr(error, estimate) = -0.14 (range -0.25..-0.04),
corr(error, true logit) = -0.34 (range -0.42..-0.27); conditioned on the true logit the error has a negative mean that grows
with rank (top 1%: -0.48σ, top 5–20%: -0.22σ, tail: +0.06σ). Ranking by the estimate is near Bayes-optimal given the codes,
so re-scoring cannot close the selection gap; more key information can (two-stage selection, E16).
